# C programs

## Build and run in VS Code

Install GCC and make sure `gcc` is available on your `PATH`.

- Open the `.c` file you want to run.
- Press **Ctrl+Shift+B** to compile it. The executable is created beside the source file.
- To compile and run it, open **Terminal > Run Task...** and select **C: Build and run active file**. Program input and output appear in the integrated terminal.

The tasks compile as C17 and enable common warnings. Generated `.exe` files are ignored by Git.
